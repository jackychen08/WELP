# Empirical alanine-dipeptide committor benchmark

[Download release v1](https://github.com/jackychen08/WELP/releases/tag/adp-committor-v1).

This release contains **368,617 conformations** of alanine dipeptide (22 atoms)
and a **54,520-conformation balanced subset**. Labels estimate the probability
of reaching state B before A from each conformation under the dynamics below.
They are Monte Carlo estimates with 95% Wilson confidence intervals.
Every conformation has 1,000 completed trials, with zero unresolved trials in
the released data (368,617,000 trials in the full set).

The balanced subset is drawn from the full dataset; these are overlapping
evaluation sets, not independent training and test splits. The benchmark was
used for evaluation, not as supervised training data for WELP.

## Download and verify

The archive is attached to the GitHub release rather than stored in Git history.
From a new download directory:

```bash
curl --fail --location --remote-name https://github.com/jackychen08/WELP/releases/download/adp-committor-v1/adp-committor-benchmark-v1.tar.gz
curl --fail --location --remote-name https://github.com/jackychen08/WELP/releases/download/adp-committor-v1/SHA256SUMS
sha256sum --check SHA256SUMS
tar -xzf adp-committor-benchmark-v1.tar.gz
cd adp_committor_benchmark_v1
sha256sum --check SHA256SUMS
```

The outer checksum verifies the downloaded archive. The checksum file inside
the archive verifies each extracted file. `manifest.json` in the repository's
`datasets/adp_committor` directory records the archive's size and checksum,
as well as the data schema and validation results.

source benchmark. Only machine-specific generation comments in the topology

parameters are unchanged. The original topology was generated by Andrew R.
Mitchell in December 2020; see also the repository's `ATTRIBUTION.md`.

## Loading the data

PyTorch is sufficient to load the tensor files. No simulation engine is needed
to use the labels.

```python
from pathlib import Path
import torch

root = Path("adp_committor_benchmark_v1")
data = torch.load(
    root / "adp_committor_test_set_balanced.pt",
    map_location="cpu",
    weights_only=True,
)
positions_nm = data["positions"].reshape(-1, 22, 3)
q_B = data["empirical_committor"]
ci_lower = data["ci_lower"]
ci_upper = data["ci_upper"]
```

Both tensor files contain float32 tensors with the following keys:

| Key | Meaning |
| --- | --- |
| `positions` | Atomic coordinates in nm; reshape each row to `(22, 3)` in PDB atom order |
| `phi`, `psi` | Backbone dihedral angles in radians |
| `empirical_committor` | `n_B / (n_A + n_B)`, the estimated probability of reaching B first |
| `ci_lower`, `ci_upper` | 95% Wilson interval for the empirical committor |

The CSV rows are in the same order as their corresponding tensor file. CSV
angles are in **degrees**; floating-point values are rounded for text export.
Use the tensors for unrounded coordinates, angles, labels, and intervals.
The CSV additionally includes:

- `n_A`, `n_B`, `n_unresolved`: outcomes of the trajectory trials.
- `idx`: row index within that file.
- `result_file`: historical per-conformation result identifier. The integer in
  `md_results_<integer>.pt` is the corresponding row in the full dataset, including
  for balanced-subset rows. The individual raw result files are not distributed.
- `bin_idx`: the original conformation-selection bin, not a balanced committor bin.
- `predicted_committor`: an inherited model prediction, not the empirical label.
  Use `empirical_committor` for evaluation.

## Dynamics and states

The source labeling configuration and the manuscript's dataset appendix specify:

- Alanine dipeptide in vacuum, CHARMM27, no nonbonded cutoff, and constrained
  bonds involving hydrogen.
- OpenMM Langevin-middle dynamics at **300 K**, friction **0.3 ps^-1**, and a
  **1 fs** integration step. Initial velocities are drawn independently from
  the Maxwell-Boltzmann distribution for each trial.
- State A centered at `(phi, psi) = (-150, 170)` degrees and state B centered at
  `(90, -50)` degrees. Each state uses an inclusive +/-10-degree window in each
  angle with periodic angular differences, giving rectangular basins.
- Basin checks every 100 steps (0.1 ps); first entry into A or B terminates a
  trial. Uncommitted trajectories are extended in batches of 1,000,000 steps up
  to a 100,000,000-step safety cap (100 ns).
- The empirical committor excludes unresolved trials from its denominator.
- Zero-based atom indices for phi are `[4, 6, 8, 14]`; for psi they are
  `[6, 8, 14, 16]`.

These labels refer to this dynamics and basin definition. In particular, the
runnable WELP `adp` example uses 310 K and its own configured basin thresholds;
changing those settings changes the committor being estimated.

## Balanced subset

The full dataset is divided into 20 empirical-committor bins of width 0.05,
with q=1 included in the final bin. Each bin is uniformly downsampled without
replacement to 2,726 conformations using NumPy's `default_rng(0)`. The selected
full-dataset indices are sorted to determine the balanced subset's row order.
The result is 54,520 rows, with equal counts in all 20 bins.

## Validation and scope

Before publication, the tensor shapes, finite values, label ranges, CSV/tensor
row correspondence, trial-count-derived committors, and Wilson intervals were
checked. Every balanced-subset tensor row and outcome count was checked against
its source row in the full dataset, and the seeded selection was reproduced.
Exact counts and checksums are recorded in `metadata.json` and `manifest.json`.

This is a release of the assembled benchmark. Raw transition-path trajectories,
individual trajectory outcomes, generation-stage model checkpoints, and the
complete simulation-generation pipeline are not included. No new dynamics were
run and no labels were recomputed for this release.
